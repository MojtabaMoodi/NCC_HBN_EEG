# NOTE:
# - Commands below are "all folds at once" (n_folds=5) for each (window, backbone) combination.
# - Backbones: cnn, resnet18, resnet34, resnet50
# - Windows: 1s, 2s, 4s
# - Source lives under user_identification/cnn_resnet_arcface/ (shared train script for CNN + ResNets).
#   Choose output folder names yourself, e.g. final_user_identification/resnet34_2s (not required to
#   include "cnn_" in the name for ResNet runs).
# - run_5fold_cv.py: optional --train_script path; all other flags before --hdf5_dir are forwarded to
#   that script; each fold runs with --hdf5_dir <root>/fold_k --output_dir <output_root>/fold_k.
#   Per-fold training log: <output_root>/fold_k/train_fold_k.log (stdout+stderr).
# - After train_user_identification_backbone.py per fold: results.json, best_model.pth, compact
#   *_user_identification_metrics.json under *_task_active/ and *_task_passive/, val_active_passive_metrics.json,
#   user_identification_active_passive_fold_metrics.json, user_identification_fold_metrics.log
#   (no *_predictions.json for user_identification — see user_identification/README.md).
#
# --- Training stability (user identification only; gender/age CNN runs unchanged) ---
# CNN.trainer.EEGTrainer for target_key=user_identification:
#   - Mixed precision (AMP) is OFF — full fp32 for ArcFace + thousands of classes.
#   - torch.compile() is SKIPPED for the same reason.
#   - Two Adam LR groups: backbone at --learning_rate; ArcFace head at learning_rate × arcface_lr_multiplier.
#   - Global gradient clipping max_grad_norm=0.2 by default (backbone + ArcFace); tune with --max_grad_norm
#     (e.g. 0.1 if updates feel unstable). Clipping limits exploding gradients; it does not fix vanishing grads.
# train_user_identification_backbone.py defaults (override with flags; pass through run_5fold_cv before --hdf5_dir):
#   - backbone=cnn: --learning_rate 3e-4, --warmup_epochs 20, --arcface_lr_multiplier 0.15 → head LR 4.5e-5; arcface_scale from TrainingConfig (256) unless --arcface_scale set.
#   - resnet*: --learning_rate 4e-4, --warmup_epochs 18, --arcface_lr_multiplier 0.22 → head ~8.8e-5; --arcface_scale 96 by default.
#   - EEGTrainer: validation-time ArcFace collapse (single predicted class many batches) no longer aborts the run;
#     training collapse still aborts. Tune LR/scale if warnings repeat every epoch.
# Useful flags: --learning_rate, --warmup_epochs, --arcface_lr_multiplier, --arcface_margin, --arcface_scale,
# --max_grad_norm, --batch_size, --dropout_rate, etc.
#
# If training aborts with "Model collapse" (many consecutive batches, one predicted class, diverse labels),
# that is an optimization / landscape issue, not proof the model cannot learn. Try in order:
#   - Defaults first (omit custom LR); or lower backbone only, e.g. --learning_rate 3e-4 (resnet) or 1e-4
#   - Softer logits: lower --arcface_scale (cnn default 256; resnet default 96)
#   - Longer warmup: --warmup_epochs 25
#   - Tighter clip: --max_grad_norm 0.1
#   - Smaller batches: --batch_size 128
