# LaBraM frozen-backbone experiments (linear probe)

Freeze all LaBraM weights except the task head (`--freeze_backbone --unfreeze_last_n_blocks 0`).
Training uses the same metrics and active/passive breakdown as `final_logs/` (JSONL `output/log.txt`).

## Prerequisites

- HDF5 data: `/home/mojtabam/scratch/processed_eeg_data_hdf5`
- Pretrained weights: `LaBraM/checkpoints/labram-base.pth`

## Run all frozen experiments (SLURM — recommended)

Submit all 9 jobs (age, gender, regression × 1s, 2s, 4s):

```bash
cd /home/mojtabam/projects/aip-aghodsib/mojtabam/EEG
chmod +x LaBraM/runs/submit_labram_frozen_*.sh LaBraM/runs/slurm_jobs/run_labram_frozen.slurm
bash LaBraM/runs/submit_labram_frozen_all.sh
```

Preview without submitting:

```bash
bash LaBraM/runs/submit_labram_frozen_all.sh --dry-run
```

Submit one segment length only:

```bash
bash LaBraM/runs/submit_labram_frozen_1s.sh   # 3 jobs
bash LaBraM/runs/submit_labram_frozen_2s.sh   # 3 jobs
bash LaBraM/runs/submit_labram_frozen_4s.sh   # 3 jobs
```

Wall time defaults: **3 days** for 1s jobs, **2 days** for 2s/4s. Optional overrides: `SLURM_PARTITION`, `SLURM_GRES`, `SLURM_TIME` (uniform override), `DATA_PATH`, `EEG_ROOT`.

### Resume incomplete 1s runs

If 1s jobs hit the time limit, resume from `checkpoint-best.pth` (weights only — `START_EPOCH` is taken from the last line of `output/log.txt`):

```bash
bash LaBraM/runs/submit_labram_frozen_resume_1s.sh
bash LaBraM/runs/submit_labram_frozen_resume_1s.sh --dry-run
```

Each Slurm invocation writes its own training log (never overwrites prior runs):

- First run: `train_slurm-<jobid>.log` (original `train.log` from manual runs is kept)
- Resume: `train_resume_slurm-<jobid>.log`
- Slurm stdout: `slurm-<jobid>.out` or `slurm-resume-<jobid>.out`

Check last completed epoch / next resume epoch:

```bash
bash LaBraM/runs/check_frozen_1s_progress.sh
bash LaBraM/runs/check_frozen_1s_progress.sh --update-note
```

## Run all frozen experiments (interactive shell)

EEG_ROOT="/home/mojtabam/projects/aip-aghodsib/mojtabam/EEG"
DATA="/home/mojtabam/scratch/processed_eeg_data_hdf5"
cd "$EEG_ROOT/LaBraM"
chmod +x runs/run_labram_frozen.sh

for TASK in age gender regression; do
  for SEG in 1s 2s 4s; do
    RUN_DIR="$EEG_ROOT/final_logs_frozen/LaBraM/labram_${TASK}_frozen_${SEG}"
    if [ "$TASK" = "regression" ]; then
      RUN_DIR="$EEG_ROOT/final_logs_frozen/LaBraM/labram_age_regression_frozen_${SEG}"
    fi
    mkdir -p "$RUN_DIR"/{output,logs}
    DATA_PATH="$DATA" TASK="$TASK" SEGMENT="$SEG" \
      bash runs/run_labram_frozen.sh \
        --output_dir "$RUN_DIR/output" \
        --log_dir "$RUN_DIR/logs" \
      2>&1 | tee "$RUN_DIR/train.log"
  done
done
